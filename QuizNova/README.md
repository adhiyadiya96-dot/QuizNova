# QuizNova

An interactive quiz platform built with HTML, CSS, Bootstrap, JavaScript and jQuery.

## Features
- Login and signup pages
- 8 subjects (Python, Java, DBMS, Data Structures, C, C++, Web Tech, OS)
- 3 difficulty levels: Easy, Medium, Hard
- 10 timed questions (15 seconds each) with instant feedback
- Result page with full answer review
- Profile and About pages

## How to run
Download or clone the project and open `index.html` in your browser.

## Project structure
```
QuizNova/
├── index.html (login)
├── signup.html, welcome.html, subject.html, instructions.html
├── start-quiz.html, loader.html, question.html, result.html
├── profile.html, about.html
├── css/style.css
├── js/quiz.js
└── assets/ (images, icons)
```

## Tech stack
HTML5, CSS3, Bootstrap 5, JavaScript, jQuery
