# 🎓 QuizNova

An interactive quiz platform where students pick a subject and difficulty, answer timed questions, and review their results.

🔗 **Live Demo:** [https://adhiyadiya96-dot.github.io/QuizNova/](https://adhiyadiya96-dot.github.io/QuizNova/)

## ✨ Features
- Login and signup pages with form validation
- 8 subjects: Python, Java, DBMS, Data Structures, C, C++, Web Tech, Operating System
- 3 difficulty levels: Easy, Medium, Hard
- 10 questions per quiz with a 15-second timer
- Instant green/red feedback on answers
- Progress bar and live score tracker
- Result page with full answer review
- Profile and About pages
- Responsive dark-themed design

## 🛠️ Built With
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- jQuery
- Browser localStorage (to keep login and quiz data)

## 🚀 How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/adhiyadiya96-dot/QuizNova.git
   ```
2. Open the `QuizNova` folder.
3. Open `index.html` in your browser.

No installation or server is needed.

## 📝 How It Works
1. Log in with any valid email and password.
2. Choose a subject and a difficulty level.
3. Read the instructions and start the quiz.
4. Answer 10 questions before the timer runs out.
5. View your score and review every answer.

## ⚠️ Note
This is a front-end academic project. Login and signup are for demonstration only, with no backend or real authentication. Data is stored in the browser's localStorage.
